# Mac电脑hot key

## Command+CHAR

| Hot Key              | Description             |
| -------------------- | ----------------------- |
| `command`+`C`        | copy                    |
| `command`+`H` or `Q` | hide or quit active App |
| `command`+`M`        | minimize window         |
| `command`+`T`        | 打开新标签页            |
| `command`+`V`        | paste                   |
| `command`+`W`        | close window            |
| `command`+`X`        | cut                     |
| `command`+`Z`        | 撤销                    |
| `command`+`tab`      | change window           |
| `command`+`space`    | finder                  |
|                      |                         |




## SCREEN CAPTURE


| Hot Key                         | Description                                         |
| ------------------------------- | --------------------------------------------------- |
| `command`+`shift`+`4`           | screenshot of certain region and save it to desktop |
| `command`+`shift`+`3`           | screenshot and save it to desktop                   |
| `control`+`command`+`shift`+`4` | screenshot of certain region and copy               |
| `control`+`command`+`shift`+`3` | screenshot and copy                                 |
| `shift`+`command`+`5`           | 截屏和录制选项                                      |
|                                 |                                                     |



## Control


| Hot Key                                  | Description                    |
| ---------------------------------------- | ------------------------------ |
| `control`+`up`                           | 调度中心                       |
| `control`+`down`                         | 应用程序窗口                   |
| `control`+`F3`                           | 将焦点移到程序坞               |
| `control`+`command`+`F`                  | 全屏使用应用                   |
| `control`+`space`                        | 选择上一个使用的输入法         |
| `control`+`option`+`space`               | 选择输入法菜单中的下一个输入法 |
| `control`+`shift`+`command`+`C`          | 将文本转换为繁体中文           |
| `control`+`option`+`shift`+`command`+`C` | 将文本转换为简体中文           |
|                                          |                                |



## Other
| Hot Key                                  | Description                    |
| ---------------------------------------- | ------------------------------ |
| `F11`                                    | show desktop                   |
| `option`+`shift`+`command`+`V` | 粘贴并匹配样式     |
| `option`+`command`+`D`         | 打开或者关闭程序坞 |
| `shift`+`command`+`N`          | 创建新窗口         |
|  |  |



## 触控板

| Gesture        | Description |
| -------------- | ----------- |
| 双指点按       | 右键效果    |
| 三指向上       | 调度中心    |
| 拇指与三指聚拢 | 启动台      |
| 拇指与三指张开 | 桌面        |
|                |             |

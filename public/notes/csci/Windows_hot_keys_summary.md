# Windows hot keys summary

## NEW DESKTOP

| Hot key                     | Description                                                  |
| --------------------------- | ------------------------------------------------------------ |
| `Win`+`Ctrl`+`D`            | create a new desktop                                         |
| `Win`+`Ctrl`+`left`/`right` | change between desktops or slide with four fingers on the touchpad |
| `Win`+`Ctrl`+`F4`           | close the current desktop                                    |
|                             |                                                              |

## VS code
| Hot key                  | Description            |
| ------------------------ | ---------------------- |
| `Ctrl` + `Shift` +`F`    | 在项目内搜索           |
| `Ctrl`+`P`               | 快速打开最近打开的文件 |
| `Alt`+`Shift`+`F`        | 格式化代码             |
| `Ctrl` + `Enter`         | 向下重开一行           |
| `Ctrl`+`Shift` + `Enter` | 在上一行重开一行       |
| `Ctrl` + `F`             | 搜索                   |
| `Ctrl` + `Alt` + `F`     | 替换                   |
|                          |                        |

- 删除一行：光标没有选择内容时，ctrl` + x` 剪切一行；ctrl +`shift + k` 直接删除一行
- 移动一行：`alt + ↑` 向上移动一行；`alt + ↓` 向下移动一行
- 复制一行：`shift + alt + ↓` 向下复制一行；`shift + alt + ↑` 向上复制一行
- ctrl + z 回退
- 选中一个词：ctrl` + d`

  通过Ctrl + ` 可以打开或关闭终端




  Ctrl+Shift+N 打开新的编辑器窗口

  Ctrl+Shift+W 关闭编辑器

  Home 光标跳转到行头

  End 光标跳转到行尾

  Ctrl + Home 跳转到页头

  Ctrl + End 跳转到页尾

  Ctrl + Shift + [ 折叠区域代码

  Ctrl + Shift + ] 展开区域代码

  Ctrl + / 添加关闭行注释

  Shift + Alt +A 块区域注释

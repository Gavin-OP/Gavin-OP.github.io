# Contributing Guide

Thanks for contributing.

## Local workflow

1. Install dependencies: `npm install`
2. Start development server: `npm run dev`
3. Lint before PR: `npm run lint`
4. Build before PR: `npm run build`

## Commit format

Use a VS Code Git Commit Plugin-compatible format:

`type(scope): summary`

Examples:

- `docs(readme): simplify project overview`
- `refactor(router): centralize route declarations`

## Pull requests

- Open PRs against `master`.
- Keep PR scope focused.
- Include screenshots for visible UI changes.
